Android App

DocPilot Qwen：手机上的开源文档 AI 助手

DocPilot Qwen 是 LucianaiB 开发的 Android 开源文档 AI 助手，把文档导入、解析、问答、摘要和模板抽取放进一个原生 App。

  • Kotlin

GitHub 6 Star文章阅读 5,03130 天完成

案例详情
背景
多数文档 AI 工具依赖桌面端或封闭产品，学生和开发者很难拆开学习和复用。
我做了什么
独立完成 UI 原型到可安装 APK；内置 5 个示例文档，无 API Key 时用本地规则兜底，演示链路不中断。

成果
完全开源并提供 APK，可直接用作 AI 应用实践项目或毕设原型。

AI 打假侦探：多模态内容验真

  • Python
  • 腾讯云 AI
  • WorkBuddy Skill

文章阅读 8,319零 SDK 依赖

案例详情
背景
AI 生成的图片、文案和视频越来越难分辨，普通人缺少一个能复现的检测链路。
我做了什么
把腾讯云 4 项 AI 识别能力串成一条检测链路，既能当命令行工具，也能作为 Skill 接入 WorkBuddy、CodeBuddy。
技术方案
Python 标准库手写 TC3-HMAC-SHA256 签名；按扩展名自动分流；视频异步两段式任务；可选多模态交叉验证。
成果
MIT 协议开源，并录制了演示视频。
